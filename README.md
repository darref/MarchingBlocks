# MarchingBlocks

**Sculpt one block. Paint a world.**

MarchingBlocks is a free and open source tool for making **non-cubic 3D tiles** and painting worlds with them.
You sculpt and texture a single "witness" block; MarchingBlocks slices it into the tiles a world needs (corners,
arches, overhangs, tunnels — the 52 tiles of the dual "marching blocks" model), then you paint cells and the right
tile appears at every corner, rotated and in context (open air or underground).

Worlds made in MarchingBlocks go to **Godot, Unity and Unreal** through an open format and three free plugins.

## What it does

- **Witness modelling and texturing** — a built-in modeller (Blender-like keys: G R S, E, I, Ctrl+B, Ctrl+R, K,
  sculpt brushes), linked copies (sculpt one tile, every copy follows), shared section borders so tiles always
  join without gaps, materials, UV unwrap, painting with layers, PBR maps derived from the albedo, animated
  textures. Or round-trip the witness through Blender as a linked `.glb`.
- **World painting** — layers with priority, brushes, selections, extrude, special shapes (tunnels, wells,
  bridges, balconies, stairs, rooms), tile variants, material transitions, foliage, water (seas, lakes, rivers,
  waterfalls, lava, swamp, acid).
- **Generate** — procedural worlds (islands, archipelagos, valleys, paths, caves, water), no AI.
- **Preshape** — dozens of parametric large shapes (mountains, volcanoes, pyramids, castles, aqueducts…) with
  a live ghost preview.
- **Crossings** — sculpted ramps and stairs laid over the terrain.
- **Play test / Play edit** — walk the world with a character, and edit it from the character's view.
- **Export** — a tileset (`.mbset`) or a whole world (`.mbworld`) in an open, documented format.

## Engine plugins

| Engine | Folder | Notes |
|---|---|---|
| Godot 4 | [`addons/marchingblocks_paint`](addons/marchingblocks_paint) | copy into your project's `addons/` |
| Unity 6 | [`engines/unity/com.marchingblocks.paint`](engines/unity/com.marchingblocks.paint) | UPM package (Built-in and URP) |
| Unreal 5 | [`engines/unreal/MarchingBlocksPaint`](engines/unreal/MarchingBlocksPaint) | copy into your project's `Plugins/` |

Each plugin reimplements the placement rule from the written rule in the format, and is checked against shared
conformance cases (`conformance.json` and friends), generated by the tool itself.

## Building from source

Requirements: **Godot 4.7** (standard build).

1. Clone with submodules:
   ```bash
   git clone --recurse-submodules https://github.com/darref/MarchingBlocks.git
   ```
2. Open `project.godot` in Godot 4.7 and run it (the main scene is `app/editor.tscn`).

The native core (`gdextension/`, C++17) is optional: prebuilt libraries for Windows and Linux are in
`addons/marchingblocks_core/natif/bin/`. Without them, the GDScript reference implementation runs (slower). To
rebuild them, see [`gdextension/README.md`](gdextension/README.md) (`scons`, a C++17 compiler).

To export: install the official Godot 4.7 export templates, then use the **Windows** or **Linux** export preset.
`DEV_TOOLS/exporter_marchingblocks.sh` runs the whole release (tests, exports, installer, plugin zips).

## Tests

Every suite runs headless:

```bash
godot --headless --path . --script res://DEV_TOOLS/test_marching_blocks.gd
```

`DEV_TOOLS/lancer_les_suites.sh` runs them all (`test_*.gd` and the app smoke test `fumee_appli.gd`). A suite is
green when it exits with code 0 and prints `N vérifications, 0 échec(s)`. The Unity plugin has a .NET runner
(`engines/unity/conformance-runner`), the Unreal core a C++ runner (`engines/unreal/core-runner`).
